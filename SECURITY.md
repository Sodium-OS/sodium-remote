# Security policy

## Reporting a vulnerability

Please report security problems privately, so a fix can ship before details are public.

1. Use GitHub's private vulnerability reporting: on this repository, open the Security tab and choose "Report a vulnerability".
2. If you can't use GitHub, write to **enterprise@sodiumos.com** with "Security" in the subject.

Include what you found, the version, and steps to reproduce it. Please don't open a public issue or pull request for a vulnerability.

We aim to acknowledge a report within a few days. We will keep you informed, and we credit reporters in the release notes unless you prefer not to be named.

## Supported versions

Only the latest release is supported. Fixes are made on the latest release; update to receive them. Sodium Remote has no automatic updater and sends no telemetry, so you have to update yourself.

## Scope

In scope: the host, the clients, the relay and the protocol in this repository, and the official release builds.

Out of scope: problems in third-party software or in systems you run yourself, and attacks that need physical access to an unlocked, signed-in computer.
