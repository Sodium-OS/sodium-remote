SudoVDA (drivers\sudovda\: SudoVDA.dll, SudoVDA.inf, sudovda.cat), the virtual display driver of "Match the display
to the connecting computer", built by Sodium Remote from https://github.com/SudoMaker/SudoVDA at commit
a4b09fa2aa731a964d0cb5d139cb1e6240e4da12 and signed with Sodium Remote's own certificate.

SudoMaker's changes: the repository's README states "MIT and CC0 or Public Domain (for changes I made, please consult
Microsoft for their license), choose the least restrictive option." The project it is a fork of,
VirtualDrivers/Virtual-Display-Driver, is under the MIT License below. The code it started from, Microsoft's
IddSampleDriver, is under the Microsoft Public License (SudoVDA-MS-PL.txt).
