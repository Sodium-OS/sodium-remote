opengl32sw.dll: the software OpenGL fallback that Qt supplies with its Windows builds
===================================================================================

opengl32sw.dll is Qt's own unmodified build of Mesa 11.2.2 (the "llvmpipe" software
renderer, Gallium "libgl-gdi" target) with LLVM 3.6.2 inside. Sodium Remote loads it
only as the fallback for a machine with no usable Direct3D 11 adapter. It is the file
opengl32sw-64-mesa_11_2_2-signed_sha256.7z from download.qt.io, taken from Qt's
repository by packaging/windows/fetch-qt.sh and checked against a pinned SHA-256.

Sources: Mesa 11.2.2, https://archive.mesa3d.org/ ; LLVM 3.6.2, https://releases.llvm.org/ .
Neither is modified by Sodium Remote, and neither is LGPL or GPL: the licenses below
only require that these notices travel with the binary.
